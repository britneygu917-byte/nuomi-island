# 糯米的小岛 · 个人作品集

> 电子信息工程 · 嵌入式软硬件开发
> 在线浏览：https://4mhq2k562t0g8.doubao.link/app/app_17ja1nqandu

一个可以「走进去」的三维个人作品集：打开是一整座小岛，操控角色走到四个区域，每块区域对应一类内容，走近就能翻开条目阅读。相比静态网页，它把简历里不容易讲清的项目过程、技术细节和成果指标，变成了可以逐层展开的实地探索。

---

## 一、技术构成

| 部分 | 方案 |
|---|---|
| 三维场景 | Three.js 0.180（程序化建模，无外部模型/贴图文件） |
| 构建 | Vite 6.4 + Rollup |
| 交互 | 点击地面寻路、WASD／方向键、地图标记、全岛视角、三主题切换 |
| 内容数据 | 单一入口 `src/portfolio.json`，由 `src/schema.js` 校验 |
| 交付形态 | 打包为单文件自包含 HTML（约 623 KB），无外部依赖 |
| 发布 | doubao-html（`lark-cli apps +deploy`） |

三种主题（森屿 / 沙洲 / 浅海）共用同一套地形与内容，切换只改变材质、植被与氛围；四个内容区域、地图标记、探索计数三者始终一致。

## 二、生成过程

整个项目分六步完成，每一步的产出物都可追溯。

### 第 1 步：素材收集与访谈

按「先定方向、再逐模块收集」的顺序完成，不预填模板内容：

- **身份**：学生 → 采用学生版四分区结构
- **素材来源**：简历「项目经历」截图 ×2、「专业技能」截图 ×1、「学生工作」截图 ×1，另有人工录入的 11 条荣誉清单
- **站名**：用户自定为「糯米的小岛」，称呼「糯米」
- **专业**：电子信息工程（写入副标题与简介，不单设模块）

### 第 2 步：四模块内容定稿

四个分区不是一次定死的，按下表逐步收敛到最终命名与展示方式：

| 序号 | 初始分类 | 调整过程 | 最终名称 | 展示方式 | 条目数 |
|---|---|---|---|---|---|
| 01 | 项目与实习经历 | 保持 | 项目与实习经历 | 挑战 / 行动 / 成果路径 | 5 |
| 02 | 科研项目 | 改为「技能展示」 | 技能展示 | 作品片签（含外链） | 4 |
| 03 | 社团与志愿者活动 | 改「竞赛荣誉」→ 再改「个人荣誉」 | 个人荣誉 | 纪念册（奖项 + 结果） | 11 |
| 04 | 自媒体与 Vibe Coding 作品 | 改为「学生工作」 | 学生工作 | 路径 + 时间线 | 1 + 2 段时间线 |

### 第 3 步：模板生成

```bash
python scripts/scaffold.py --brief portfolio.json --output nuomi-island
```

复用森林 / 沙洲 / 浅海三套主题地形、漫游角色、自由寻路、边界碰撞、地图、音效与内容面板交互；个人内容全部来自本次材料，未套用模板示例履历。生成后通过 `schema.js` 校验：四模块、`id` 唯一且符合 slug 规则、项目条目必带非空 `chapters`。

### 第 4 步：角色定制

默认模板角色与本人形象不符，按用户提供的参考图重写 `src/models.js` 的 `makeHiker()`，共三轮：

| 版本 | 问题 | 调整 |
|---|---|---|
| v1 | 头发成丸子、V 领三角生硬、手臂与身体脱节 | 改长直发帘 + V 领 + 手臂贴身 + 直筒牛仔裤 |
| v2 | 刘海过重、马甲下摆有横条 | 刘海高度与角度微调、去掉下摆横条、裤腰同色 |
| v3 | 定型 | 中分刘海 + 两侧长发垂到胸前 + 背发、细黑圆框眼镜 |

最终外观：中性浅棕长直发（无橘调）、细黑圆框眼镜、米白衬衫 + 灰蓝 V 领针织马甲、浅蓝直筒牛仔裤（裤腰 / 侧缝 / 裤脚三线）、白帆布鞋。同时删除原模板的**双马尾、相机、相机背带、青绿背包及肩带、水壶**。

改造只动 `makeHiker()`，场景、地形、植被、营地、镜头与 `animateHiker()` 一行未改；发丝摆动继续由原 `braids` 数组驱动，走路摆臂、身体起伏、发丝晃动全部正常。调试时用临时页面单独立起纯白场景、相机正对角色逐版比对，定稿后删除临时文件。

### 第 5 步：构建与验收

```bash
npm ci
npm test    # 11/11 通过
npm run build
```

浏览器实测覆盖：四模块经页脚导航、地图、岛屿标记均可到达；条目切换与章节翻页（1/3 → 2/3 → 3/3）；三主题切换；全岛视角；玩法指南；外链跳转目标；718×667 窗口无横向溢出；控制台无报错。另补 `public/favicon.svg` 消除默认图标 404。

### 第 6 步：单文件打包与发布

发布通道只接收单文件自包含 HTML，而原工程是多文件 Vite 产物，因此增加两个文件完成内联：

- `vite.single.config.js`：`inlineDynamicImports: true`、`cssCodeSplit: false`、`base: "./"`，把 Three.js 与业务代码合成单一 bundle
- `build-single.mjs`：把 `dist-single/` 的 `index.html` + `app.css` + `app.js` 合并成一个 HTML，剥离 icon link、转义 `</script`

产物 `nuomi-island-standalone.html`（623,504 字节），外部引用数 0，用 `file://` 直接打开即可完整运行（WebGL 场景、内容面板、外链均正常，控制台干净）。随后发布：

```bash
lark-cli apps +deploy --file-path ./nuomi-island-standalone.html
lark-cli apps +release-get --app-id app_17ja1nqandu --release-id <release_id>
```

发布为异步任务，轮询到 `status=finished` 才拿到线上地址。后续更新复发布到同一 `app_id`，链接不变。

## 三、数据结构

个人内容只有一个入口：`src/portfolio.json`。改内容不需要碰任何场景代码。

### 顶层

```json
{
  "version": 1,
  "profile": { "name": "糯米", "title": "糯米的小岛", "subtitle": "...", "intro": "...", "links": [] },
  "modules": [ ... ]   // 必须为 3 或 4 个
}
```

### 模块字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一 slug，`^[a-z][a-z0-9-]*$`，如 `projects` |
| `name` | 是 | 分类名称，建议 4–8 字 |
| `short` | 是 | 场景标签，≤6 字 |
| `kind` | 是 | `gallery` / `awards` / `research` / `projects` |
| `items` | 是 | 条目数组；明确无内容时用 `[]` 且置 `emptyConfirmed: true` |
| `intro` `links` `metrics` `timeline` | 否 | 模块级补充信息 |

### 条目字段

| 字段 | 适用 | 说明 |
|---|---|---|
| `title` `summary` | 全部 | 标题与一句话结论 |
| `chapters` | projects / research | 必填非空，通常三章：问题 / 做法 / 结果 |
| `kicker` | 全部 | 时间、赛事级别、角色等短说明 |
| `metrics` | 全部 | `[{value,label}]`，只放有依据的数字 |
| `rank` `result` | awards | 奖项与结果 |
| `url` | 全部 | 真实外链，无则省略 |
| `image` `alt` | 全部 | 生成前为本地路径，脚本复制为 `/assets/module-N-item-M.ext` |
| `sourceNote` | 全部 | 数据口径或团队／个人边界说明 |

### 本项目数据规模

| 模块 | kind | 条目 | 其他 |
|---|---|---|---|
| 项目与实习经历 | projects | 5（各 3 章，共 15 章） | 8 项量化指标 |
| 技能展示 | gallery | 4 | 1 条外链（GitHub） |
| 个人荣誉 | awards | 11 | 11 项 result |
| 学生工作 | projects | 1（3 章） | 2 段时间线、3 项指标 |

## 四、完整作品呈现

### 01 · 项目与实习经历

> 从需求到联调，把电路和代码做成能跑的东西。

**① 基于 AI 大模型的桌面机器人** — 2026.06–2026.09 · 毕设作品
指标：3 × 30 轮网络分级测试｜4 个集成硬件模块
- 要做什么：ESP32-S3 + C（ESP-IDF）+ 嘉立创EDA + I2S + Wi-Fi + MCP，做能听懂话、会做动作的桌面机器人
- 我做的事：独立完成 PCB 设计与打样焊接，集成主控、电源、音频、舵机驱动四个模块；开发外设驱动与 I2S 音频采集，部署 MCP 本地 Agent，打通「语音 → 大模型 → 舵机动作」链路
- 验证结果：按良好／一般／较差三档网络各跑 30 轮，验证弱网与异常下健壮性，未出现死机复位

**② 指天椒病虫害 AI 识别系统** — 2026.01–2026.03 · 竞赛项目
指标：mAP@0.5 = 0.953｜F1-score = 0.91｜640×640
- 问题与场景：大棚实地采集、自行标注，无现成数据集
- 我的方法：多源数据集融合训练方案 + 数据增强，YOLOv11 训练调优
- 结果与落地：实现摄像头实时推理与离线语音播报；与物联网工程师协作把检测画面推送到端侧

**③ 自动化抓取与码垛控制系统** — 2025.12–2026.02 · 团队项目 · 核心成员
- 要解决的问题：按草包位置状态执行固定时序动作，调度传送电机与液压气缸
- 我做的事：STM32F103 GPIO + 外部中断采集多路限位／接近开关；FreeRTOS 多任务调度与消息队列，输出控制电平
- 结果：完成从自动抓取到分层码垛的整段动作

**④ 简易 FM 收音机设计与制作** — 2025.09–2025.12 · 独立硬件项目
指标：50–180MHz｜实测 87.0MHz 校园广播
- 从原理图开始：原理图 + PCB 全自绘，自采购器件、整机焊接，搭射频—解调—音频放大链路
- 调出来的问题：排查啸叫与灵敏度不足，示波器逐级看信号定位
- 结果：可接收本地多个 FM 电台，含 87.0MHz 校园广播

**⑤ 基于 STM32 的简易数字示波器** — 2025.03–2025.06 · 负责人
指标：>800KSa/s｜测量相对误差 <5%｜档位 10+
- 要做的功能：波形显示 + 频率与峰值参数 + 扫描速度与垂直灵敏度可调
- 我做的事：定时器触发 ADC → DMA 搬运 → FFT 处理整条采集链路；改采样频率与 LCD 映射比例做档位
- 指标结果：最高实时采样 >800KSa/s，误差 <5%，档位均超 10 个，波形无明显失真

## 七、说明与边界

- **数据来源**：全部条目来自本人提供的简历截图与口头补充，未使用模板示例或他人经历；团队项目在 `sourceNote` 中标注个人与团队的边界。
